# Python Pattern Programs (Problems 78–112)

This folder contains beginner-friendly Python solutions for the star, number, alphabet, and advanced patterns visible in your screenshots.

## How to run
1. Extract the ZIP file.
2. Open this folder in VS Code.
3. Open a `.py` file, for example `right_angled_triangle.py`.
4. Run it in the terminal:
   ```powershell
   py right_angled_triangle.py
   ```
5. Enter the number requested by the program.

Each pattern is in its own descriptively named Python file. Some patterns may look slightly different from the screenshot depending on spacing and the number you enter.
